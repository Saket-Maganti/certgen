\begin{abstract}
Generative-model comparisons rely on finite-sample metric estimates chosen over sample sizes, seeds, checkpoints, and metrics -- a selection process under which naive fixed-sample interpretations are not valid. CertGen is a metric-agnostic decision-certificate framework that decides whether one model is certifiably better under a declared discrepancy metric, sample budget, and preprocessing lock, using a betting confidence sequence that is valid under optional stopping. The same e-process yields a per-comparison e-value, so e-BH controls the false discovery rate across a whole leaderboard despite the dependence from a shared reference set, and reports both a samples-to-decision (compute-savings) number and an audit of how many reported wins are statistically decided. The clean core places rigorous certificates only on bounded-kernel MMD/CMMD streams; FID and FD-DINOv2 remain descriptive.
