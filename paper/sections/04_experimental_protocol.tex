\section{Experimental Protocol}

Benchmarks and model pairs are selected only after provenance gates pass. Each run requires released samples or reproducible checkpoints, a preprocessing lock, validated feature caches, metric reproduction checks, and a non-claim pilot before any evidence-candidate promotion.
