# CertGen Kaggle dependency and asset guide

The Python 3.11 T4x2 profiles and locks are aligned under `requirements/`. The diagnostic uses the minimal `kaggle_t4x2_diagnostic` profile and `kaggle-diagnostic.lock`; it does not install the preflight stack. Generation, features, and preflight have separate locks and share `kaggle-constraints.txt`. The active CLIP route is Transformers-based, so neither `timm` nor `open-clip-torch` is required.

Supported dependency modes are `KAGGLE_INTERNET_ON_INSTALL`, `PRIVATE_WHEELHOUSE_OFFLINE`, and `USE_PREINSTALLED_VALIDATED`. Online mode installs only missing/incompatible requirements under the stage constraints. Offline mode recursively discovers any mount containing an exact v2 `wheelhouse_manifest.json`, checks locked versions/specifiers and CPython 3.11 Linux x86_64/manylinux or `py3-none-any` tags plus exact membership and every wheel hash, then installs with `--no-index`, `--find-links`, constraints, and the stage lock. Source distributions, wrong tags/versions, unmanifested wheels, and conflicts fail. Preinstalled mode installs nothing and fails if any version/import is incompatible.

Each input bundle includes `requirements/lock_integrity.json`, binding stage, profile, stage-lock SHA-256, constraints SHA-256, and resolved dependency names before installation. After installation, the notebook writes an authenticated-input-bound restart marker and stops before GPU/model work. Restart the kernel and rerun the same cell: it detects the marker automatically, verifies the same input identity, reruns version inspection, actual imports, and `python -m pip check`, then consumes the marker.

Private asset datasets may use any Kaggle dataset slug, mount name, and safe nesting. CertGen discovers aggregate `asset_manifest.json`, then matches asset ID, model/extractor ID, revision, license status, loader type, exact membership, per-asset manifest hash, inventory hash, and every file hash. `asset_resolution_report.json` maps each identity to a concrete existing snapshot root and is passed to workers, which revalidate the per-asset manifest. Runtime mount paths are never written into frozen scientific configuration. Identical mounts are deduplicated; conflicting content fails.

The minimum CIFAR pilot uses Inception and the Transformers CLIP loader. Public archives contain no model/extractor weights; CLIP remains private and `local_files_only=True`. `claim_allowed=false`.
