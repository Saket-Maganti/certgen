## Universal controls

All commands run from the repository root unless noted. Preserve immutable inputs and copied-back ZIPs. Freeze hashes before execution. Use `resume` only for the identical run identity; use `restart` to quarantine and rebuild the same identity; use `force_new_run` for a distinct run. Stop on every failed validator. Planning runtimes are not measurements. Kaggle rows require a real T4x2 run and have not been validated here.

## Notebook policy summary

All five canonical notebooks share the same tagged bootstrap, secure input, environment, network/asset, disk, run-mode, subprocess, status, integrity, deterministic ZIP and copy-back cells. Generation notebooks use batched/OOM runtime; feature notebooks additionally require observed preprocessing equality. Their local static and fixture proofs do not substitute for real Kaggle execution.

## Stop conditions

Stop on invalid reference/provenance, unresolved license/revision/config, environment bootstrap failure, asset-cache incompleteness, wrong GPU visibility, worker crash/timeout, minimum-batch OOM, corrupt/duplicate/missing sample or shard, preprocessing mismatch, unsafe ZIP, cache identity/dimension failure, metric/sanity failure, unfrozen family, fingerprint failure, inconsistent ranking family, or paper-firewall failure.
