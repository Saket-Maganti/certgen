# Claims Policy

V1 outputs are smoke, mock, synthetic, planned, or descriptive-only artifacts.

Allowed V1 language:

- smoke artifact
- non-evidence
- planned
- placeholder
- toy
- contract validation

Blocked in generated non-evidence reports:

- we find that
- we show that
- certified result
- paper evidence
- real evidence
- model A beats model B
- published wins are undecided
- ranking changes
- compute saving
- empirical result

Future evidence-grade claims require real-data gates, verified manifests, and a later audit protocol.
