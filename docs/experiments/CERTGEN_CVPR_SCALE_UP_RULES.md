# CertGen CVPR Scale-up Rules

1k -> 10k only if provenance, preflight, caches, metric reproduction, null/obvious-gap controls, family freeze, and pilot interpretation pass. 10k -> 50k only for comparisons where added budget answers a registered question. CIFAR -> benchmark 2 only after pilot code/assumptions survive. Benchmark 2 -> 3 only if breadth is scientifically necessary. Image -> video only if the image paper is strong and temporal theory is separately specified. Pilot output is not paper evidence; any future promotion requires immutable lineage and the paper gate.
