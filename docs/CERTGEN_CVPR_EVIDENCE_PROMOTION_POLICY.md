# CertGen CVPR Evidence Promotion Policy

Planning artifacts cannot become run logs by renaming. Run logs cannot become caches. Caches require schema/hash/provenance validation. Sanity artifacts are controls, not model results. Pilot artifacts remain single-benchmark/non-generalized. No paper evidence exists now; future promotion requires immutable lineage, passed metric/sanity/statistical/multiplicity gates, preregistration match, release safety, and an explicit approved artifact ID. Tests, synthetic results, notebook images, runtimes, and fixtures are permanently non-paper evidence.
