# V2 Registry Schema

`NO_REAL_EVIDENCE`

Fill registry rows only with verified metadata. Use `TBD`, `unknown`, or `needs_user_verification` when a value is not verified. Incomplete rows should be marked `needs_user_verification`, not `eligible`.

The V2 registry tracks released samples, checkpoints, feature caches, reported metric values, sample size, preprocessing notes, license status, and blockers.
