# Deterministic Replay and Minimal Recomputation

Replay compares registered stages and changed paths to the canonical dependency order. Paper-only text does not trigger a scientific rerun; ranking code invalidates ranking; certificate code invalidates certificates and downstream analyses; preprocessing invalidates features and downstream stages; model checkpoints invalidate generation and downstream stages. Valid shards may rebuild a corrupt ZIP. The planner emits invalidated and reusable artifacts plus exact commands, and the verifier rejects overlap or study-hash drift.
