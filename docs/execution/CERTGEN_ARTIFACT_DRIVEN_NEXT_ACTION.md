# Artifact-Driven Next Action

`certgen next-action` verifies artifact-registry hashes and resolves the study, family, merge/cache, draw, controls, certificate-inputs, certificates, and ranking artifacts that actually exist. Late-stage commands quote those resolved paths and report their artifact IDs, working directory, expected output artifact, validator, runtime, network and recovery policy. A declaration without a verified artifact blocks; invented convenience paths are never substituted.
