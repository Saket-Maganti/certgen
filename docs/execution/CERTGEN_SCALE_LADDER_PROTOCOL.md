# Prospective Scale Ladder Protocol

The frozen ladder is 1k integrity pilot, 10k evidence pilot, and 50k full candidate. Each scale records entry conditions, sample counts, models, extractors, comparisons, controls, budgets, artifacts, stop/repair/promotion rules, and allowed decisions. Invalid pipelines stop; repair repeats the same frozen protocol. Promotion uses integrity and resolution status, never a favorable direction. Optional DINO, CFM, or second-benchmark activation requires its explicit prospective gate.
