# V5 Real Pilot Runbook

`NO_REAL_EVIDENCE`

The required real-pilot flow is:

1. Validate V5 state and claim boundaries.
2. Fill and validate a real provenance ledger.
3. Validate or materialize feature caches.
4. Lock preprocessing.
5. Reproduce one reported metric point estimate.
6. Run a clean-core certificate pilot in non-claim mode.
7. Render a pilot report card.
8. Run the V5 audit.
9. Decide whether a later gate can promote outputs to evidence candidate.

Do not execute heavy downloads or GPU jobs from the default bundle.
