# Immutable Run Capsule Protocol

`capsule build` requires a valid frozen study and resolvable registry rows. It snapshots run identity, study, profile, registries, configuration, sanitized asset manifests, dependencies, output schema, provenance parents, instructions, and validation commands. ZIP metadata is fixed for byte determinism. Private Kaggle input capsules and public reproducibility capsules are distinct; public capsules reject weight suffixes. Capsules do not embed results and never grant claims.
