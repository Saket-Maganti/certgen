# V2 FID Policy

`NO_REAL_EVIDENCE`

FID is difficult for anytime-valid confidence sequences because it is a biased nonlinear functional of empirical means and covariances. V2 permits FID and FD-DINOv2 as point estimates or descriptive report fields only.

Allowed:

- descriptive FID point estimate;
- FD-DINOv2 point estimate;
- clearly labeled block-level experiment that is not a claim basis.

Forbidden:

- rigorous anytime FID certification;
- FID as the sole claim basis;
- any certificate-like FID output without a descriptive or experimental-not-for-claims label.

A later upgrade would need a proof-backed implementation and audit before this policy changes.
