# Compute Accounting Contract

Each execution record contains images generated, images feature-extracted, GPU seconds, CPU seconds, samples at first decision, fixed-budget samples, retrospective savings, and online realized savings.

Runtime counters are execution metadata, not scientific evidence. Retrospective savings answer what could have been avoided after replaying a completed fixed-budget run. Online realized savings count work actually avoided by a prospective stopping action. These fields are never interchanged or summed without an explicit analysis rule.
