# Qualitative Model-Pair Gallery Contract

Every gallery panel binds representative image paths, model IDs, feature-space decisions, descriptive point-estimate direction, certificate status, first-decision sample count, and limitations. Image selection rules must be recorded before rendering result-bearing galleries.

Every output carries this disclaimer: representative images are illustrative and are not proof of distribution-level superiority. Galleries cannot override an unresolved, invalid, or feature-specific certificate conclusion.
