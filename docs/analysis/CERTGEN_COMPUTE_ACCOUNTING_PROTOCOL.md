# Compute Accounting Protocol

Required fields cover downloads, model load, preflight, generated/featured images and GPU seconds, CPU merge/certificate time, first-decision and fixed budgets, retrospective and realized online savings, disk, and archive sizes. Each record is exactly one of `PLANNING_ESTIMATE`, `MEASURED_PREFLIGHT`, `MEASURED_REAL_RUN`, or `DERIVED_REAL_MEASUREMENT`. Planning estimates may never set measured status, and retrospective savings may never be reported as realized online savings.
