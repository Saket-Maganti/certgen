# CertGen V1 README

CertGen V1 builds a claim-safe foundation for metric-agnostic decision certificates over generative-model comparisons.

V1 includes package scaffolding, dataclass schemas, feature-cache contracts, toy CPU metrics, a clean-core certificate scaffold, FID policy gates, registry templates, and reproducibility docs.

V1 does not include real feature extraction, real benchmark audits, paper-ready claims, or verified related-work citations.
