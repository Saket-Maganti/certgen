# Forbidden Claims V5

`NO_REAL_EVIDENCE`

Forbidden before claim-eligible real runs:

- any undecided-fraction value;
- any statement that reported wins fail or are settled by CertGen;
- any ranking movement claim;
- any compute-savings number;
- any real benchmark result;
- any rigorous FID certificate claim unless a separate audited method exists;
- any statement that CertGen is a new metric;
- any statement that FID is useless or wrong;
- any statement that most papers are wrong.
