## Difference from V2

V2 implemented the statistical clean-core scaffold and smoke certificate path.

V3 hardens everything around the first real pilot:

- provenance;
- feature-cache validation;
- feature extraction planning;
- metric reproduction;
- pilot orchestration;
- replay;
- no-claim reporting;
- registry availability;
- V3 audit.

## What V3 still should not do

- no real empirical claims;
- no fabricated benchmark audit;
- no ranking movement claim;
- no rigorous FID certificate unless later solved;
- no paper-facing result without real validated features and claim gates.

## V3 final expected status

A successful V3 repo should be able to say:

> The infrastructure is ready to validate real feature caches and run the first clean-core pilot in non-claim mode. No paper result exists unless real data was supplied and all gates passed.
